Let's talk about making programs run faster.

  • Optimize?

Snoozefest

I'm trying for plain English. Call me on technical jargon.

What is optimization?

  • A program runs
  • it works, too
  • but it's prohibitively slow!
So, we make the slow part of the program faster.

But when?

Pareto's 80/20

Roughly adapted to software, 90% of time is spent in 10% of code.

Hottie

Optimization too early is really bad

We should forget about small efficiencies, say about 97% of the time: premature optimization is the root of all evil.
- Don Knuth (smart dude)
  • Optimization makes code less readable, obvious
  • It's probably a waste of time
  • Increases rigidity

So what do the geezers say?

Make it run, then make it right, then make it fast.
- Kent Beck (smart geezer)
  • We start optimizing a Percolate feature only once it is complete.

How do we optimize?

Through a process called profiling.
